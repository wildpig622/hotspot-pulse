# 已恢复的采集范围与实现契约

本文件记录公开采集范围、来源政策与实现约定。历史窗口与用户2026-11-09更新的自然月窗口分别标注；不发布内部对话链接。

## 恢复到的范围

- 监控未来90天的演唱会/演出、会展、体育赛事、节庆、学生假期/官方放假调整，以及可能影响酒店住宿的大型会议和峰会。
- 仓库保留28个经营城市：成都、南京、重庆、杭州、武汉、西安、深圳、南昌、广州、长沙、贵阳、沈阳、洛阳、珠海、昆明、郑州、南宁、徐州、合肥、苏州、福州、德阳、遂宁、济南、厦门、金华、天津、兰州。
- 监控记录明确重点排查西安、济南、成都、南京、杭州、武汉、重庆、深圳、广州、长沙；并记录过汉中等客源地假期对目标城市的潜在影响。
- 已知事项保留，不因简报“不重复报告”而从持久台账消失；新增、补录、改期、延期、取消必须可区分。
- 活动举办日期、售票/报名日期、建议关注入住日期、客源地放假及周末连休窗口分别记录。
- 来源、发布时间、发现时间、证据访问时间、范围和例外保留；RSS及历史助手回答只用于发现。未经证实不自动升级verified，潜在影响不等于真实住宿增量。

历史中已出现的覆盖样本包括深圳APEC/高交会、成都林忆莲、南京王嘉尔/张杰、武汉张杰、济南分区秋假，以及汉中客源地秋假。历史事实必须重开来源后才能补入结构化记录；读取失败的仍列缺口。

## 本次落实

`config/monitoring-scope.json`作为机器可读范围：6条分类检索线路，每城市每类型最多50条，180天公告回看，4路并发。未来90天是默认经营观察窗口，长期线索仍保留供后续观察；公告回看窗口与活动日期窗口独立。

结构化来源登记与新闻线索分开保存。明确读到正文日期的登记可关联多篇新闻；缺少活动身份的新闻继续作为独立线索，不能仅凭同城同日自动归并。假期必须保留区县、学段、批次和例外；客源地不冒充举办城市。

覆盖状态保持partial；请求成功与内容完整性分别报告。采集及部署仍为手动，刷新网页只读已有快照。
