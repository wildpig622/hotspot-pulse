## 搜索Agent实验怎样执行

本会话助手实际执行城市/类别检索、页面读取、实体追查与交叉核验：初始18组搜索覆盖三城六类任务，没有具体活动名；另有8组自适应搜索、9组定向回归搜索、1组新发现实体验证。共10次搜索工具调用、18次网页读取尝试。具体初始词与近期检索轨迹见 agent-trace.json、recency-followup.json。

叶世荣不是人工预置参考：带recency=7的“天津 演唱会 官宣 加场 开票”结果先出现11月25日加场资讯，再按该新发现名称找到11月24日的天津广播和大麦认证账号。那英、徐良、老狼、国考、研考、天津市考、济南校历、既有学术会议均归定向回归；即使开放搜索碰巧搜到，也不计开放发现。

本轮共形成9条开放决策记录，其中8条有候选日期、1条未定档信号。**不是9项已核验新增事件，也不是自主发现率分母。** 部分只有索引支持，部分日期有冲突。其余5条新决策及保留的旧官方记录属于回归。

开放决策分布为济南5、天津4；西安尚未形成非回归的高价值开放候选。这一缺口继续列为未验收，不用定向命中的那英或ICCLL补计。

实现包含可替换检索provider、公开正文读取、来源短证据匹配与复核输出。Bing匿名RSS替代方案实际测试三城后未取得可用结果，遵守robots和失败边界；没有登录、绕过验证或开通付费API。可用检索链路是本会话提供的公开网页搜索工具。**这不是已经验证的无人值守搜索服务。** config/phase4-agent-decisions.json 是检索后的决策日志，不是搜索输入；命名网址重放只用于复核，不能称作自主发现。

重放核验：`python -m scripts.phase4_experiment --output docs/phase4-review-2026-11-27 --private review/phase4-private`；离线表格：`python -m scripts.phase4_report`。SearchAgent支持provider搜索结果到正文读取的独立测试，不加载业务基准；默认匿名provider当前不可用，完整无人值守方案尚需替代检索接口与独立验收。

## 四条链路的对照与保留修复

traditional_collector.json 是本轮同一观察日实抓三城秀动首屏，33条记录。search_agent.json、official_notice.json、social_signal.json 分别导出Agent决策、官方证据和社交信号；同一记录可同时属于多个证据来源，不能把各表求和。首屏预算不代表现有采集器全站能力。

comparison.json 给出记录ID口径的独有贡献、重叠及重复观察。incremental-comparison.json 逐项按城市、日期和名称线索对照本轮首屏与Phase3冻结清单：本轮决策中的高价值活动未在这些对照记录中匹配到。这里既有预算限制，也有跨源身份待核，**不能声称完整采集器真实漏掉了所有这些活动，更不能把差值当因果增益**。未完成人工标注的真实发现率、日期准确率、城市准确率、误报和跨源重复率保持null。

Phase2有12条官方日期记录。Phase3缺了10个旧记录ID，其中全国研考在另一官方源以新来源ID出现，属于身份谱系变化；其余9条日期记录涉及国考、天津考区/市考、四项济南校历及FICMSS。根因在 phase3_report.py：all_rows仅取当前发现和公开列表，旧官方事件仅参与身份匹配，没有并入日历。此外还有官方TLS/连接失败、动态栏目无链接、校历多区间留待审核等发现瓶颈。

本轮融合层补上 retain_official：仍有效的12项全部保留原ID、状态和上次证据时间；未重新发现不代表取消。重新打开旧正文但没有重新验证全部日期，也不假更新日期核读时间。取消/延期/拒绝记录可以留存审计，但不列为可执行经营候选。日期冲突另标需复核，不覆盖人工结论。见 official-retention-audit.json。

## 经营分级、独立基准及剩余缺口

operating_relevance_candidate 与 review_status 分离：考试/会展/目的地演出优先复核；常态本地脱口秀/驻场活动单列routine_local；学校假期列origin_market_review；全国公告未确认地方时列scope_review。人数、跨城观众比例、住宿增量等级与收入影响仍未知，未凭场馆或演出性质虚构数值。

tests/fixtures/phase4-holdout.json 单独保存2个既有独立政府演出许可参考，以及5个负例控制。参考活动名及正文URL不进入初始查询或决策输入。它是配置隔离的盲测包，**不是独立人工盲评**；两项正例本轮尚未命中，所有总体验收指标继续未验收。负例包括过去活动、旧年度校历、开票日当演出日、全国日期误推地方等。小样本和人工独立性不足仍需后续补齐，未把200条标注作为试用前提。

来源限制包括匿名Bing搜索、动态场馆栏目、项目官网robots阻止、西电直接读取与网页工具通道差异、天津科技大学重定向循环、票务售罄状态缺少当前一手证据。通过公开新浪页面读取认证账号帖子，不等于微博站内搜索已覆盖；没有证明小红书/抖音覆盖。体育任务检索出现计划名录和过去赛事，未得到可核实的三城未来重大赛事，不用年度计划补造日期。

cost-stability.json 记录原始请求检查、耗时相加、流量及缓存重放，重放耗时不冒充真实采集耗时。没有开通付费搜索或模型服务；本会话搜索/模型计费信息未暴露，总货币成本未知。单次试验、有限首屏与访问差异不能作为生产稳定性结论。

公开变更只提交必要字段、链接、短日期证据、失败元数据和代码；没有新上传完整正文或原始响应包，联系方式经过过滤。原始响应仅在忽略目录中供本地复核；既有阶段的历史归档未在本轮重新发布。新回归测试覆盖有效官方事件保留、时间不假刷新、人工结论、未知规模、近期时间语义、provider搜索到正文读取及最小化导出。
