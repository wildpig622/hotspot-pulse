## 日期200条专项

基线 c4c2c52 有17,532条新闻，16,407条缺 start_at。本轮固定种子20261126，按三城/其他城市与原有类型轮转分层，无放回抽取200条，见 date-sample/sample-200.json。此样本会过采稀少层，不能直接外推总体发生率。Phase 2 的17,079条审计是更早 ca514b5 快照，保留在上一阶段目录，不能混用分母。

200条都指向Google News包装链接，其 robots 禁止本次正文路径，因此原文日期是否存在仍为未知，不能标作“原文无日期”。通过独立标题搜索另找回4篇原文或权威替代报道，保存 date-followup/annotations.json：

- 1篇只写“日前召开”，不拿报纸日期当活动日。
- 3篇有可定位的过去活动日期；其中1篇是同一活动的权威替代报道，并非已确认的RSS原始正文。
- 助手结构化草案有3条通过字面证据门槛：相对规则新增1个数字日期建议、2个活动日期语义建议；全部是过去活动，新增未来有效事件为0。门槛通过不等于事实核验通过。

没有调用外部付费LLM。这里测试的是本会话助手对真实已读正文的结构化草案，保留了原文引句、原始日期词和年份证据；尚未建成批量LLM服务，也未证明200条准确率。**独立人工已完成数为0；T2未完成。** 五类标注枚举和待审字段已准备，不能用模型草案替代人工标签。

## 对照样本与准确率边界

tests/fixtures/phase3-benchmark.json 有36项日期/范围样本，合并同一校历年、同一公务员分科后为32个活动族。样本来自上一阶段官方留出项、独立公开搜索及人工转录旧票务卡片，未用本轮解析结果生成预期日期。

基准名称和正文URL只在抓取结束后的独立核对程序中读取；发现程序不加载基准文件。32个唯一参考网址中，25个有可读正文；另有访问失败或脚本空页，不把HTTP200当作读到正文。

known-misses.json 明确列出14项未命中，包括国考、天津本地考试、济南校历、部分会议和演出许可。**独立人工验收参考数仍为0；不能宣称满足至少30项独立人工业务验收。**

## 处理层及兼容性

event_observations.py 区分 scheduled、unscheduled、status_change、market_signal，保存实际 observed_at、来源发布时间和日期、原文证据及观察历史。状态包含观察、官宣、开票、售罄、加场、取消、延期。重复重放不重复插入，同一源在不同时间的观察独立保留，旧观察晚到不覆盖新状态。单条社交帖子不能证明热点持续性。

官方同一正文、同一城市、同一日期区间的唯一匹配才恢复旧记录ID；共享栏目页、多事件或改期歧义留待人工身份关联。西安和济南会议恢复 Phase 2 记录ID。92个与既有 v2 重合的来源记录在内存合并试验中保持原 canonical ID，没有自动升级 verified，见 v2-compatibility.json。未定档和市场信号保存在独立观察文件中，不塞入要求日期的现有接口。

修复并回归了成绩公布日误作考试日、在线课程截止日当线下事件、导航标题覆盖文章标题、页脚城市混入、研讨会关键词遗漏、多城社交帖误归单城等问题。秀动默认90天行为保留，仅隔离实验显式传365天。

## 成本、稳定性与后续

官方及票务实验归档242项请求检查：196成功、46失败或阻止，约8.10MB；归档请求耗时相加172.144秒。第三方CLI累计77.844秒，9组搜索外另有诊断和热榜。235份成功归档响应含评估与日期补读，gzip解压后的SHA-256全部核对通过。

这些数值不包含丢弃的异常中断尝试、独立网页检索、助手令牌与人工成本，也不是精确总费用。没有付费数据服务或外部付费模型调用。两次列表测试已出现间歇性超时，尚无长期稳定性或生产SLA结论。

下一步任务按业务缺口排列：找回200条原文并完成独立人工标签；建立至少30项无旧列表选择偏差、具备原始证据的人工验收样本及负例；适配官方动态栏目/校历多区间和大型会展排期；核实社交线索的主办方与年份，扩大突发官宣、加场、应援和电竞留出测试；确认跨源身份关系及本地考点/客源范围，再评估经营转化。没有安排自动部署或生产采集。

公开审阅响应保存在 responses.zip：230个归档对象对应235项成功请求检查。自动审批曾拒绝上传含个人电话和邮箱的正文，因此115项请求的公开副本使用联系方式脱敏派生件；未脱敏原始取证副本保存在忽略目录 review/phase3-original-evidence，未加入本轮PR变更。

response-manifest.json 记录公开对象、正文及原始响应SHA-256，privacy-review.json 记录脱敏范围。事件身份、名称、城市、日期和观察时间保持不变。无需解包即可回放公开证据；原文日期可结合本地原始副本及原始哈希复核，不能把脱敏派生件称作原始网络响应。打包排除了没有成功请求记录可回溯的中断遗留对象。

本目录报告可离线重建：`python -m scripts.phase3_report --output docs/phase3-evidence-2026-11-26`。真实采集需分别执行 phase3_discovery、phase3_public、phase3_platforms；最后一个要求忽略目录 review/last30days-skill-cn 中存在上述固定版本。采集后用 `python -m scripts.phase3_bundle --output docs/phase3-evidence-2026-11-26` 校验并重打证据包，本地raw文件不单独提交。不要调用生产 collect/build_files 作为本实验替代。
