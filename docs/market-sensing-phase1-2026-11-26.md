## 这次处理了什么

- 审计采集器、主题分类、日期语义、覆盖矩阵、v2 消费合同、网页筛选器、测试和 Actions。
- 新增配置驱动的 `exam` 主题，覆盖考研、国考、省考、事业单位、教资、高考、中考、自学考试、成人高考和职业资格。
- 将假期与会议关键词扩展到校历、开学/返校、春假/秋假、学术会议、年会、研讨会、行业大会和论坛。
- 将检索路由从采集器代码中的固定循环移到 `monitoring-scope.json`，质量门禁按配置路由集合校验。
- 扩展考试日期角色：考试/初试/笔试/面试与报名、缴费、准考证等动作分开；现有 `start_at`、`event_date_role`、`content_kind`、事件 ID 和 v1/v2 字段保持兼容。
- 为覆盖 API、v2 meta 和网页类型筛选器增加动态主题目录；旧快照没有目录时仍使用旧的安全回退。
- 新增 `config/official-sources.json`，只记录来源设计与验证状态，不把来源目录直接转成活动事件。

## 数据转化漏斗

`官方来源目录/公开 RSS`
→ `按城市×主题×查询路由发现`
→ `原始新闻或正文候选（保留 URL、发布/观察时间）`
→ `主题分类 + 内容性质分类`
→ `日期抽取与日期角色分离（考试、报名、假期、会议）`
→ `城市匹配、条件/取消过滤和稳定事件身份`
→ `活动登记、新闻候选、来源候选分层`
→ `v1 快照 + coverage 台账 + v2 canonical events/changes`
→ `网页/消费者只读展示`

任何一层缺少正文、城市、日期角色或可复现身份时，记录留在 pending/uncertain/not_run/partial；不会通过“检索成功”自动升级为 verified，也不会把报名或搜索结果日期写成活动日期。
